# Cajero Automático en C

## Descripción
Este proyecto simula un cajero automático que permite a usuarios autenticarse y realizar operaciones bancarias básicas.

## Funcionalidades
- Inicio de sesión con usuario y clave
- Consulta de saldo
- Depósito de dinero
- Retiro de dinero
- Validación de fondos
- Menú interactivo

## Compilación
gcc cajero.c -o cajero

## Ejecución
./cajero
